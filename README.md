## 🎯 FileMate 2.0 核心目标

**一句话目标**：构建一个属于大学生自己的 AI Knowledge Brain（个人知识大脑）。

**三大服务场景**：

| 场景 | 具体能力 |
|------|----------|
| 🔬 科研规划 | 论文阅读笔记、实验数据、文献管理，AI 梳理研究脉络 |
| 🏆 竞赛规划 | 竞赛通知、备赛资料、deadline 日程，AI 制定备赛计划 |
| 📚 学习规划 | 课件、作业、考试资料，AI 建立知识体系、发现薄弱点 |

**为什么做这个**：

1. **大学生面临"信息过载"** — 四年积累几千个文件，散落各处，命名混乱
2. **现有工具只是"工具"** — Notion、Obsidian 需要手动整理，不能主动分析你的学习进度
3. **FileMate 要做"主动规划"** — 你只需上传文件，AI 会告诉你：该复习线性代数了、下周挑战杯截止……

## 🔬 核心科研问题（RQ）

| 编号 | 问题 | 技术挑战 |
|------|------|----------|
| **RQ1** | 如何从大学生分散的学习资料中自动构建高质量的个人知识图谱？ | 多格式统一理解、实体关系抽取、知识融合 |
| **RQ2** | 如何让 AI Agent 在"理解你的知识状态"之后，主动给你规划学习？ | 长期记忆、图谱推理、主动规划 |
| **RQ3** | 如何建立动态的、可持续更新的个人知识状态模型？ | 时序分析、知识追踪、推荐算法 |

## 📊 与市场产品的差异

| 产品 | 特点 | FileMate 2.0 优势 |
|------|------|-------------------|
| Notion / 飞书 | 功能强大，需要手动整理 | 自动理解文件、主动提取知识 |
| Obsidian | 双向链接，本地存储 | 不是"笔记工具"，是"成长规划助手" |
| 网盘 AI | 只能归类文件 | 能理解内容、规划学习 |
| ChatPDF | 对话式，每次手动上传 | 长期记忆、了解你的学习轨迹 |

**FileMate 2.0 核心差异**：
- 📁 文件是入口，不是终点
- 🧠 知识图谱 + 长期记忆
- 🤖 主动规划，而非被动回答
- 🎓 大学生专属，垂直场景

## 📖 快速开始

```bash
# 1. 克隆仓库
git clone https://github.com/cooooooosdas/Filemate.git
cd FileMate

# 2. 创建虚拟环境
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 配置 LLM
cp .env.example .env
# 填入 DEEPSEEK_API_KEY / OPENAI_API_KEY 等

# 5. 验证安装
python -c "from filemate.llm_client import LLMClient; print('OK')"

# 6. 启动开发服务器
python -m filemate.ui.app
# 或
cd filemate/web && npm run dev
```
